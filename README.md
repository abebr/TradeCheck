# TradeCheck (تریدچک) 🚀

A modern, lightweight Pre-Trade Checklist & Risk Calculator Android app built with **Jetpack Compose** and **Material 3**.

## Features
- **Pre-Trade Checklist**: Verify higher timeframe trends, trigger patterns, stop-loss, risk limits, and high-impact news.
- **Custom Rules**: Add and remove personal trading rules seamlessly.
- **One-Tap Reset**: Reset checklist status between trades.
- **Live Risk-to-Reward Calculator**: Calculate R:R on the fly with instant setup warnings.
- **Bilingual & RTL**: Switch between Persian (فارسی) and English (EN) dynamically with native Vazirmatn typography.
- **Modern UI**: Adaptive app icon and dark slate trading aesthetic.

## Architecture
- 100% Kotlin & Jetpack Compose (No legacy XML layouts)
- Material 3 Design
- State management with Kotlin Flow & State hoisting
- Automated Cloud CI/CD via GitHub Actions
